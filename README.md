# Nobi2-brand

Streetwear / premium-thrift storefront inspired by a dark editorial shop layout. Built with React, Vite, Tailwind CSS, and React Router.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## What’s included

- Home matching the reference layout (hero, perks, categories, trending, drops, Instagram, footer)
- Shop with category filters and search
- Product pages, collections, about, contact
- Client-side cart (localStorage) and a demo checkout (no real payments)

Demo catalog uses Unsplash photography.
